# Переход с версии 0.1

В версии 0.2 основной конфиг находится в личной папке приложения.

1. Остановите старый `serve` через Ctrl+C. Если его запускает MCP-клиент, отключите там сервер.
2. Установите новую версию по README.
3. Импортируйте прежний конфиг, указав его реальный путь:

```powershell
notification-mcp setup --import-config "F:\Portfolio\notification-mcp\config.toml" --client codex
```

Перезапустите Codex. По умолчанию подключается stdio-сервер, которым Codex управляет сам;
отдельный `notification-mcp start` не требуется. Для общего фонового HTTP-сервера вместо этого
выполните `notification-mcp start` и `notification-mcp connect codex --transport http`.

## Переход с файлового токена на переменную окружения

Создайте пользовательскую переменную `TELEGRAM_BOT_TOKEN`, затем замените только MCP-запись:

```shell
codex mcp remove notifications
notification-mcp connect codex --token-env
```

После полного перезапуска Codex сервер перестанет читать сервисный `config.toml`. Очередь и
привязка Telegram сохраняются в той же пользовательской базе. Старый конфиг автоматически не
удаляется: при необходимости сначала сохраните резервную копию, затем удалите содержащий токен
файл вручную. Не удаляйте каталог `var`, если хотите сохранить очередь и выбранный чат.

Импорт переносит настройки и копию SQLite с очередью и привязкой `/start`.
Токен из переменной окружения должен быть доступен во время импорта; он сохранится в новом
локальном файле. Старые файлы остаются на месте. Не запускайте затем старую копию сервера
с той же очередью: это отдельная копия данных.

Если личный конфиг уже существует, `setup` его не перезаписывает. Со старым файлом можно
продолжать работать без переноса, явно указывая `--config` перед каждой командой.

Если в прежнем конфиге задан `chat_id`, он остаётся фиксированным. Чтобы включить выбор чата
через `/start`, удалите эту строку в новом конфиге, перезапустите сервер и отправьте `/start` боту.

Для очень старых записей очереди, созданных до поддержки токена в файле, сохраняйте прежнюю
переменную окружения до доставки: в этих записях ещё нет идентификатора бота.

Перед переносом на другой компьютер отдельно сохраните личный конфиг и базу.
Файловые каналы при импорте сохраняют прежние абсолютные пути назначения — при удалении старой
папки измените эти пути.
